# コンポーネント境界

Instant Translator は単一の文脈で構成する。振る舞いの正本は [翻訳仕様](translation.md)、
画面の正本は [UI 仕様](ui.md)、語の定義は [CONTEXT.md](../../../CONTEXT.md) にある。
この文書は、それらを実現するコンポーネントの責務の分かれ目を定める。

## 一覧

| コンポーネント | 責務 |
| --- | --- |
| Workspace | 作業の現在値を保持する |
| Detection | 原文の言語を判定する |
| Session | 翻訳をいつ始め、どの結果を採用するかを決める |
| Inference | ローカル推論サーバと話す |
| Prompts | 翻訳条件からモデルへの指示を組み立てる |
| Persistence | 作業状態を端末内へ保存し復元する |
| UI | 表示と入力を受け持つ |

## Workspace

- 原文、訳文、翻訳方向、翻訳方式、口調、接続状態、翻訳状態を保持する。
- 翻訳方向は自動検出、日本語から英語で固定、英語から日本語で固定の三態と、
  直前に確定した翻訳方向を持つ。
- 翻訳の実行、通信、保存は行わない。

## Detection

- 原文から日本語、英語、曖昧のいずれかを判定する。
- 判定のために翻訳モデルを呼ばない。推論サーバへ要求を出さない。
- 判定結果を翻訳方向へ適用するかどうかは決めない。それは Session の責務である。

## Session

- 原文または翻訳条件の変化を受け取り、400 ミリ秒のデバウンスを経て翻訳を開始する。
- 翻訳開始時に翻訳方向を確定する。自動検出中は Detection の判定を用い、
  曖昧なときは直前に確定した翻訳方向を維持する。固定中は判定を用いない。
- 進行中の翻訳を中断し、古い結果を破棄する。
- 最新の原文と最新の翻訳条件に対応する結果だけを Workspace へ書き戻す。
- 原文が入力上限を超えている間は翻訳を開始しない。
- 文章を分割したり、要約したりしない。

## Inference

- ローカル推論サーバの OpenAI 互換 chat completions（`POST /v1/chat/completions`）へ
  ストリーミングで要求し、届いた断片を返す。
- サーバの health エンドポイント（`GET /health`）で接続状態を確認する。
- 接続先ホストは `127.0.0.1` である。ポートは環境変数 `INFERENCE_PORT` から読み、未設定は `8080` である。
- 推論プロセスを起動しない。モデルファイルを管理しない。
- プロンプトの内容を決めない。開始時期や中断の判断もしない。

## Prompts

- 翻訳方向、翻訳方式、口調の組み合わせから、モデルへ渡すメッセージを組み立てる。
- 結果が訳文だけになるよう指示する。前置き、説明、引用符、モード名を出させない。
- 言語判定をモデルへ依頼しない。翻訳方向は与えられたものを使う。
- 通信を行わない。

## Persistence

- 原文、完成済みの訳文、翻訳方向、翻訳方式、口調を作業状態として端末内へ保存し、復元する。
- 生成途中の訳文で保存済みの完成結果を上書きしない。
- 消去操作を受けて、保存済みの原文と訳文を削除する。
- 外部へ同期しない。履歴として複数の翻訳を蓄積しない。

## UI

- Workspace の現在値を表示し、利用者の操作を Workspace と Session へ渡す。
- 見た目、文言、状態の示し方の正本は [UI 仕様](ui.md) である。
- 推論サーバと直接話さない。プロンプトを組み立てない。

## 依存の向き

- UI は Workspace と Session へ依存する。
- Session は Workspace、Detection、Prompts、Inference、Persistence へ依存する。
- Detection、Prompts、Inference、Persistence は互いに依存しない。
- Workspace はどのコンポーネントにも依存しない。
