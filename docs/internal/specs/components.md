# コンポーネント境界

Instant Translator は単一の文脈で構成する。振る舞いの正本は [翻訳仕様](translation.md)、
画面の正本は [UI 仕様](ui.md)、語の定義は [CONTEXT.md](../../../CONTEXT.md) にある。
この文書は、それらを実現するコンポーネントの責務の分かれ目を定める。

## 一覧

| コンポーネント | 責務                                           |
| -------------- | ---------------------------------------------- |
| Workspace      | 作業の現在値を保持する                         |
| Session        | 翻訳をいつ始め、どの結果を採用するかを決める   |
| Profiles       | プロファイルの形と検証を定める                 |
| Inference      | プロファイルの推論先と話す                     |
| Prompts        | 翻訳条件からモデルへの指示を組み立てる         |
| Persistence    | 作業状態とプロファイルを端末内へ保存し復元する |
| UI             | 表示と入力を受け持つ                           |

## Workspace

- 原文、訳文、原文言語、訳文言語、意訳の有無、口調、接続状態、翻訳状態を保持する。
- 原文言語は指定しない、日本語、English、訳文言語は日本語、English を取る。
- 翻訳の実行、通信、保存は行わない。

## Session

- 原文または翻訳条件の変化を受け取り、400 ミリ秒のデバウンスを経て翻訳を開始する。
- 原文言語と訳文言語が同じ言語になる明示指定の変更は受け付けず、無視する。
- 進行中の翻訳を中断し、古い結果を破棄する。
- 最新の原文と最新の翻訳条件に対応する結果だけを Workspace へ書き戻す。
- 完成した訳文には、対応する原文、実際に用いた原文言語と訳文言語、意訳の有無、口調を紐付けて保存する。
  再読み込み時はこの対応が一致した場合だけ完了として復元し、一致しなければ古い訳文を非 current として
  現在の原文を再翻訳する。
- 原文が入力上限を超えている間は翻訳を開始しない。
- 入力上限の判定と Workspace へ渡す原文の文字数は、Unicode の書記素クラスタ（利用者が知覚する 1 文字）で数える。
- 文章を分割したり、要約したりしない。
- 初回の接続確認を開始し、接続確認には世代を付けて古い応答を無視する。再試行では接続確認を開始せず、
  最新の翻訳一回の成否で接続状態を更新する。
- 訳文を一つも受け取らずにストリームが終了した場合は翻訳失敗とし、保存済みの完成訳文を変更しない。
- プロファイルの一覧と選択状態を保持し、追加・編集・削除・切り替えを受け付けて Persistence へ保存する。
  切り替え時と選択中プロファイルの編集時は、接続確認を開始し現在の原文を再翻訳する。
  プロファイルが常に一つ以上残るよう、最後の一つの削除を無視する。

## Profiles

- プロファイル（表示名、ベース URL、API キー、モデル名、サンプリングパラメータ）の型と、
  入力の検証・正規化、初期シードの定義を持つ。
- 予約キー（`messages`、`stream`、`model`）を含むパラメータを拒否する。
- 通信も保存も行わない。

## Inference

- 与えられたプロファイルの推論先の OpenAI 互換 chat completions
  （`POST {ベース URL}/chat/completions`）へストリーミングで要求し、届いた断片を返す。
  プロファイルのパラメータをボディへそのまま含め、モデル名が空でなければ `model` を付ける。
- 接続確認は `GET {ベース URL}/models` で行う。API キーが空でなければ
  どちらの要求にも `Authorization: Bearer` ヘッダーを付ける。
- HTTP 401 と 403 は認証失敗として、他の失敗と区別して報告する。
- どのプロファイルにも同じ手順を用いる。プロバイダ種別による分岐を持たない。
- 推論プロセスを起動しない。モデルファイルを管理しない。
- プロンプトの内容を決めない。開始時期や中断の判断もしない。どのプロファイルを使うかも決めない。

## Prompts

- 原文言語、訳文言語、意訳の有無、口調、原文から、モデルへ渡すメッセージを組み立てる。
- 言語は与えられたものを使う。自分では判定しない。
- 通信を行わない。

## Persistence

- 原文、完成済みの訳文、原文言語、訳文言語、意訳の有無、口調を作業状態として端末内へ保存し、復元する。
- プロファイルの一覧と選択状態を、作業状態とは別のキーで端末内へ保存し、復元する。
  無効な保存状態は移行せず破棄する。
- 完成済み訳文には、対応する原文、実際に用いた原文言語と訳文言語、意訳の有無、口調を保存する。
- 現在の原文と完成済み訳文の対応が一致しない保存状態は、古い訳文を現在の完了として復元しない。
- 旧形式の保存状態は移行せず、無効な状態として破棄する。
- 生成途中の訳文で保存済みの完成結果を上書きしない。
- Session から受け取った消去後の作業状態を保存する。
- 外部へ同期しない。履歴として複数の翻訳を蓄積しない。

## UI

- Workspace の現在値を表示し、利用者の操作を Workspace と Session へ渡す。
- 見た目、文言、状態の示し方の正本は [UI 仕様](ui.md) である。
- 推論先と直接話さない。プロンプトを組み立てない。
- プロファイルの切り替えと編集の操作を Session へ渡す。入力の検証には Profiles の検証を用いる。

## 依存の向き

- UI は Workspace、Session、Profiles（型と検証）へ依存する。
- Session は Workspace、Prompts、Inference、Persistence、Profiles へ依存する。
- Inference と Persistence は Profiles の型へ依存する。
- Prompts、Inference、Persistence は互いに依存しない。
- Workspace と Profiles はどのコンポーネントにも依存しない。
