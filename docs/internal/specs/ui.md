# UI 仕様

Instant Translator の画面の正本。振る舞いは [翻訳仕様](translation.md)、コンポーネントの責務は
[コンポーネント境界](components.md)、語の定義は [CONTEXT.md](../../../CONTEXT.md) を正本とする。

## 目的

翻訳したい文章へすぐ集中でき、入力、翻訳、確認、コピーまでを迷わず完了できる画面を定義する。

機能を増やして便利さを演出するのではなく、訳文の読みやすさ、状態の分かりやすさ、
入力に対する反応の滑らかさによって品質を感じられる画面にする。

## 前提

- 個人が日常的に使う、デスクトップ中心のローカル Web アプリである。
- 画面の中心的な仕事は、原文の入力と訳文の取得だけである。
- 翻訳は入力を契機として自動的に始まり、翻訳開始ボタンは存在しない。
- 翻訳履歴、アカウント、共有、複数候補、解説画面は存在しない。
- 画面は一つの翻訳ワークスペースだけで構成し、設定や状態表示によって主作業を妨げない。
- 原文言語は原文ペイン、訳文言語、意訳、口調は訳文ペインへ置き、折りたたみや歯車の奥へ隠さない。
- 成功、処理中、警告、失敗は、アイコン、文言、色の組み合わせで区別し、色だけへ依存しない。
- ライトモードとダークモードの両方を提供する。
- この文書は、外部サイト、画像、別リポジトリを参照しなくても実装できる内容とする。
  部品と既定値は MUI（Material UI）のものを指す。

## デザインコンセプト: Material の道具

飾らない Material Design のユーティリティアプリとして構成する。

- MUI の既定値をほぼそのまま使い、独自のデザインシステムを作らない。
- 既定値からの逸脱は最小限とし、逸脱は翻訳本文の読みやすさに資するものだけとする。
- 作業対象である原文と訳文は輪郭付きの `Paper` に載せ、それ以外のコントロールは
  背景の上へ直接置く。

## 視覚言語（テーマ）

- MUI のテーマを `colorSchemes: { light: true, dark: true }` と CSS 変数で構成する。
- 既定のモードは OS の設定に従う。ヘッダー右端のモード切り替え IconButton で明示的に
  切り替えられ、明示的な選択は localStorage へ保存される
  （MUI の `useColorScheme` の既定の挙動をそのまま使う）。
- パレットは MUI の既定値を変更せずに使う。
  - ライト: background.default `#fafafa`、background.paper `#ffffff`、primary `#1976d2`。
  - ダーク: background.default `#121212`、background.paper `#1e1e1e`（elevation による明度変化を含む）、
    primary `#90caf9`。
  - error、warning、文字色も MUI の既定値を使う。
  - 独自の色相を追加しない。
- 書体は Roboto と Noto Sans JP を @fontsource でアプリ自身が同梱して提供し、
  外部のフォント CDN へ依存しない。
- タイポグラフィは MUI の既定のタイプスケールを使う。
  唯一の逸脱として、原文と訳文の本文だけを 18px、行高 1.7 とする。
- 角丸と影は MUI の既定値を使う。原文ペインと訳文ペインは `Paper variant="outlined"` とし、
  影を持たせない。
- メタラベル（ペイン見出しなど）は Typography の `overline` バリアントを使う。
- 本文の選択色は上書きせず、ブラウザと OS の標準に任せる。
- キーボードフォーカスの表示は MUI の既定に任せる。例外として原文の入力領域は、
  Paper の輪郭が primary 色へ変わることでフォーカスを示す。

## 画面構成

- アプリは一つの翻訳画面だけを提供する。
- ページ遷移、サイドバー、タブ式ナビゲーションは設けない。
- 全体を `Container maxWidth="lg"` に収め、上から AppBar、翻訳ワークスペースの順に構成する。
- AppBar は `position="static"`、`color="default"`、elevation 0 とし、
  境界線を持つバーを積み重ねない。左にアプリ名、右に接続状態の Chip と
  カラーモード切り替えの IconButton を配置する。
- 歯車アイコン、プロフィール、通知、追加メニューは配置しない。
- 独立したツールバーは設けず、各操作を作用先のペインへ配置する。
- 翻訳ワークスペースは、輪郭付きの Paper 二枚
  （原文ペインと訳文ペイン）を `Stack direction={{ xs: 'column', md: 'row' }}` で並べる。
  デスクトップ（MUI の `md` ブレークポイント 900px 以上）では左右同幅、
  900px 未満では原文を上、訳文を下へ積み重ねる。
- 360px 幅まで横スクロールを発生させない。

```text
┌─────────────────────────────────────────────────────────┐
│ Instant Translator            (ローカル: 接続済み) [◐]  │
│ ┌───────────────────────┐    ┌───────────────────────┐  │
│ │ 原文 [自動判定        │    │ ▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬ │  │
│ │       (日本語) ▾] 消去│    │ 訳文 [English ▾] □意訳 │  │
│ ├───────────────────────┤    │ 口調 [標準 ▾]    コピー│  │
│ │ 入力すると自動で翻訳  │    ├───────────────────────┤  │
│ │ します                │    │ ここに翻訳結果が表示  │  │
│ │                       │    │ されます              │  │
│ │             0 / 4,000 │    │                       │  │
│ └───────────────────────┘    └───────────────────────┘  │
└─────────────────────────────────────────────────────────┘
```

`[◐]` はカラーモード切り替えの IconButton、`□ 意訳` は Checkbox、
訳文ペイン上端の `▬▬▬` は翻訳待機中・翻訳中だけ動く LinearProgress の帯を表す。
操作帯の下の `├──┤` は本文との区切り線を表す。各ペインの操作帯は一行で、
図では紙幅の都合で折り返している(狭い画面では実際に折り返す)。

## 情報の階層

- Paper に載る原文と訳文を画面内で最も大きく、最も読みやすい要素とする。
- アプリ名、接続状態、言語と訳文設定は翻訳本文より視覚的に弱くする。
- 原文言語、訳文言語、意訳の有無、口調は常に確認できるが、本文を不必要に押し下げない。
- 健全な接続状態は小さな Chip で控えめに示す。
- 接続に問題がある場合だけ、状態の色と文言を強める。
- 文字数は通常時には目立たせず、3,200 文字を超えると警告色で強調する。
- 各コントロールは一つの役割だけを持ち、同じ操作を複数箇所へ置かない。
- アイコンだけで意味が確定しない操作には、表示ラベルまたは支援技術向けの名前を持たせる。

## ヘッダーと接続状態

- アプリ名は AppBar の左側に配置する。
- 接続状態は小さな outlined の Chip として AppBar の右側に配置する。
  - 接続済み: 「ローカル: 接続済み」
  - 接続確認中: 「ローカル: 確認中」
  - 接続失敗: 「ローカル: 未接続」
- 接続失敗の Chip は error 色を使い、かつ文言でも他の状態と区別する。色だけに依存しない。
- 接続失敗時は、簡潔な説明と再試行操作を訳文ペインへ表示する。
- カラーモード切り替えの IconButton は AppBar の右端に配置する。
- 接続状態の変化によって AppBar の高さやアプリ名の位置を変えない。

## ペインの操作帯

- 原文と訳文の見出しは、それぞれの言語 Select と同じ行へ配置する。
- 各ペインの操作は見出しと同じ一行の操作帯へまとめ、操作帯の下端に
  `divider` 色の 1px の区切り線を引いて本文と区切る。
- 操作帯の高さと本文の開始位置は、原文ペインと訳文ペインで揃える。
- 視覚上は「原文」「訳文」だけを見出しとして表示し、「原文の言語」「訳文の言語」という重複ラベルは追加しない。
  各 Select は支援技術向けの名前として「原文の言語」「訳文の言語」を持つ。
- 言語はその言語自身の表記（「日本語」と「English」）で示す。
- 原文言語 Select は「自動判定」「日本語」「English」を持つ。既定は「自動判定」とする。
- 訳文言語 Select は「日本語」「English」を持つ。既定は「English」とする。
- 原文言語と訳文言語の Select では、もう一方で明示選択中の同じ言語を無効化する。
- 入れ替え操作と「固定」の状態表示は設けない。
- 意訳は訳文ペインの操作帯に MUI の `Checkbox` と `FormControlLabel` で表示する。初期状態は未チェックとする。
- 口調は意訳の隣に MUI の `Select`（size small）で「標準」「チャット」「技術文書」「カジュアル」から選ぶ。
- 意訳の有無または口調を変更すると、現在の原文を自動的に再翻訳する。確定ボタンは置かない。
- 狭い画面では訳文の操作帯を折り返すことを許容し、横スクロールを発生させない。

## 原文ペイン

- 文字数表示と入力上限は、Unicode の書記素クラスタ（利用者が知覚する 1 文字）で数える。
- ペインは `Paper variant="outlined"` とする。
- ペインの上端に overline の「原文」ラベルを左、消去操作の小さなテキスト Button「消去」を右へ配置する。
- 「消去」は原文がある場合だけ利用できる。
- 原文言語が自動判定で、日本語または英語を判定できた場合は、言語 Select の表示値を
  「自動判定 (日本語)」または「自動判定 (English)」とし、判定結果を Select の中で示す。
  判定結果のための専用の行や caption は設けない。
- 空の状態では「入力すると自動で翻訳します」とプレースホルダーで短く示す。
- 入力領域は Paper の中の枠なし `InputBase`（複数行）とし、Paper の中の利用可能な高さを使用する。
  入力領域そのものには別の枠や面を設けない。Paper が入力領域の輪郭である。
- 入力領域がフォーカスを持つ間は、Paper の輪郭を primary 色にする。太い輪郭を重ねない。
- 文字数はペインの下端へ固定し、入力内容の増減で位置を変えない。
  通常時は caption サイズ、text.secondary で「N / 4,000」と表示する。
- 3,200 文字を超えると、文字数表示を warning.main にする。
- 4,000 文字を超えた場合は error.main で、「原文が 4,000 文字を N 文字超過しています」の形で
  超過文字数を具体的に表示する。
- 上限超過時も原文の編集、選択、コピーを妨げない。
- 入力へ戻ったとき、スクロール位置とカーソル位置を不必要に失わない。

## 訳文ペイン

- ペインは `Paper variant="outlined"` とする。
- ペインの最上端に高さ 4px の帯を常に確保し、翻訳待機中と翻訳中だけ
  primary 色の不確定 `LinearProgress` を表示する。それ以外のときは空の帯として残し、
  進捗表示の出入りでレイアウトを動かさない。
- 帯の下に、overline の「訳文」ラベルを左、コピー操作を右へ配置する。
- コピー操作は ContentCopy アイコン付きの小さな Button「コピー」とする。
  訳文ペインの上端だけに置き、下端へ重ねて配置しない。
- 「コピー」は完成した訳文が存在する場合だけ利用できる。
- コピー成功時はラベルを短時間「コピーしました」へ切り替え、
  Snackbar やトーストなど画面を覆う通知を追加しない。
- 逐次生成中の訳文と完成済みの訳文を、レイアウトを動かさず同じ領域へ表示する。
- 翻訳状態を次のように表示し分ける。
  - 原文が空: 本文に text.disabled で「ここに翻訳結果が表示されます」とだけ表示する。
    原文のプレースホルダーと同じ背景的な案内文として扱い、テキスト選択の対象にせず、
    支援技術へ読み上げない。説明やイラストを追加しない。
  - 翻訳待機中: LinearProgress が動く。直前の訳文がある場合は text.disabled で残し、
    現在の結果として扱わない。
  - 翻訳中: LinearProgress が動く。最初の訳文が届いた時点で直前の訳文を置き換え、
    通常の文字色で逐次表示する。
  - 完了: LinearProgress を消し、訳文を通常の文字色で表示する。
  - 言語重複: `Alert severity="warning"` で「原文は日本語として検出されました。別の訳文言語を選択してください。」
    の形で判定結果と必要な操作を表示し、直前の訳文を現在の結果として表示しない。
  - 接続失敗: `Alert severity="error"` で「ローカル翻訳に接続できません」と表示し、
    アクションとして「再試行」ボタンを配置する。
  - 翻訳失敗: `Alert severity="error"` で「翻訳を完了できませんでした」と表示し、
    アクションとして「再試行」ボタンを配置する。
  - 入力上限超過: 「原文が 4,000 文字を超えています」と表示し、
    超過前の訳文を現在の結果として表示しない。
- エラー文は謝罪や曖昧な表現を使わず、何が利用できないかと次の操作を示す。

## モーションとフィードバック

- 主なモーションは、訳文ペイン上端の不確定 LinearProgress に絞る。
- LinearProgress は翻訳待機中と翻訳中だけ動き、それ以外は空の帯として何も表示しない。
- 逐次生成中は文字そのものを主役とし、大きなスピナーやスケルトンで覆わない。
- 完了時に成功色へ切り替えず、LinearProgress を消して通常状態へ戻す。
- 入力、設定変更、コピーのフィードバックは即座に返す。
- アニメーションによって本文の位置やペインの大きさを変えない。
- 独自のアニメーションを追加しない。OS の視差効果を減らす設定を尊重し、
  MUI の LinearProgress の標準表現はその範囲で許容する。

## キーボード操作

- 初回表示時は原文入力へフォーカスする。
- 文字編集、選択、コピー、貼り付け、Undo、Redo は OS とブラウザの標準操作を使用する。
- 原文言語、訳文言語、意訳、口調、コピー、消去、再試行、
  カラーモード切り替えへ Tab キーで到達できる。
- Tab 移動の順序は、画面の視覚的な読み順と一致させる。
- Enter、Space、Escape、矢印キーは、MUI の各コントロールの標準的なキーボード操作に従う。
  口調の Select は矢印キーで項目間を移動し、Enter で選択し、Escape で選択せずに閉じて
  トリガーへフォーカスを戻す。
- アプリ独自のキー組み合わせは設けない。
- ブラウザや OS の標準ショートカットを上書きしない。
- 自動翻訳の開始にキー操作を要求しない。

## アクセシビリティと画面幅

- キーボードだけで原文入力、原文言語、訳文言語、意訳、口調、コピー、消去、再試行、
  カラーモード切り替えへ移動できる。
- フォーカス位置を常に視認できる。原文入力は Paper の輪郭の変化、
  それ以外は MUI 既定のフォーカス表示で示す。
- 状態を色だけで伝えない。
- 本文と操作文字は、ライト・ダーク両モードで WCAG 2.2 AA 相当のコントラストを持つ
  （MUI の既定パレットはこれを満たす）。
- 翻訳開始、完了、失敗を支援技術へ通知するが、入力のたびに過剰な読み上げを行わない。
- 逐次生成される各トークンを個別に読み上げず、翻訳開始と完了を状態として通知する。
- 口調の選択肢はキーボードと支援技術から選択でき、現在の選択を通知する。
- 200% まで拡大しても、主要操作と本文が欠落せず、横スクロールを要求しない。
- デスクトップ中心のアプリとして、操作対象は十分な大きさと間隔を確保する。
  44px 四方のタッチ最適化は要求しない。
- OS の視差効果を減らす設定を尊重する。

## 受け入れ条件

### 画面の理解

- 初回表示で、輪郭付きの Paper によって、原文をどこへ入力し、訳文がどこへ表示されるか理解できる。
- 翻訳ボタンを探さずに、初期値のまま翻訳を開始できる。
- 原文と訳文が画面内で最も強い視覚的優先度を持つ。
- 原文言語、訳文言語、意訳の有無、口調、接続状態を本文と混同せず確認できる。
- 翻訳中、完了、失敗、上限超過をレイアウトの大きな変化なしに区別できる。
- 入力中や逐次生成中に主要な操作位置が移動しない。
- 履歴、アカウント、共有、候補一覧、解説、仕様外の設定入口が画面へ追加されていない。

### 操作

- コピー操作が訳文ペインの上端にあり、一回の操作でコピーでき、成功を確認できる。
- 入力消去操作が原文ペインの上端にある。
- 意訳の有無と口調を、別の設定画面や折りたたみを開かずに確認・変更できる。
- 意訳が有効かどうかを、色を見分けられなくても判断できる。
- 口調の選択肢を開閉しても、翻訳ペインや主要操作の位置が動かない。
- 設定変更後、翻訳ボタンや確定操作を要求されない。
- 原文言語を自動判定、日本語、English から選択できる。
- 訳文言語を日本語、English から選択できる。
- 原文言語と訳文言語に同じ言語を明示指定できない。
- 自動判定した原文言語と訳文言語が同じ場合は、理由と別の訳文言語を選ぶ必要があることを確認できる。
- ヘッダーのモード切り替えでライトとダークを切り替えられ、明示的な選択が再読み込み後も保持される。
- 明示的に切り替えていない場合、モードが OS の設定に従う。

### 画面幅とアクセシビリティ

- 900px 以上では原文と訳文が左右、それ未満では上下の自然な読み順になる。
- 360px 幅で横スクロールが発生しない。
- 200% 拡大時にも主要操作と本文が欠落しない。
- 初回表示後、クリックせずに原文を入力できる。
- OS 標準のコピー、貼り付け、Undo、Redo を利用できる。
- Tab キーだけで主要な操作へ視覚的な順序で移動できる。
- フォーカス位置を常に視認できる。
- 口調の Select を Escape キーで閉じ、トリガーへフォーカスを戻せる。
- ブラウザまたは OS の標準ショートカットがアプリによって上書きされない。
- 翻訳開始のために Enter や独自ショートカットを押す必要がない。

### 視覚言語

- パレットが MUI の既定値のままである。ライトで background.default `#fafafa`、
  background.paper `#ffffff`、primary `#1976d2`、ダークで background.default `#121212`、
  background.paper `#1e1e1e`、primary `#90caf9` が使われている。
- MUI の既定パレットにない独自の色相が追加されていない。
- 原文ペインと訳文ペインが `Paper variant="outlined"` で、影を持たない。
