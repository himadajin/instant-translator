# UI 仕様

Instant Translator の画面の正本。振る舞いは [翻訳仕様](translation.md)、コンポーネントの責務は
[コンポーネント境界](components.md)、語の定義は [CONTEXT.md](../../../CONTEXT.md) を正本とする。

## 目的

翻訳したい文章へすぐ集中でき、入力、翻訳、確認、コピーまでを迷わず完了できる画面を定義する。

機能を増やして便利さを演出するのではなく、訳文の読みやすさ、状態の分かりやすさ、
入力に対する反応の滑らかさによって品質を感じられる画面にする。

## 前提

- 個人が日常的に使う、デスクトップ中心のローカル Web アプリである。
- 画面の中心的な仕事は、原文の入力と訳文の取得だけである。
- 翻訳は入力を契機として自動的に始まり、翻訳開始ボタンは存在しない。
- 翻訳履歴、アカウント、共有、複数候補、解説画面は存在しない。
- 画面は一つの翻訳ワークスペースだけで構成し、設定や状態表示によって主作業を妨げない。
- 翻訳方式と口調は常時見える 1 行の設定バーに置き、折りたたみや歯車の奥へ隠さない。
- 画面は少色で、文字と余白を中心に構成する。
- 成功、処理中、警告、失敗は、アイコン、文言、線、明度、動きの組み合わせで区別し、色だけへ依存しない。
- ダークモードは提供せず、OS の設定に関係なくライトテーマを維持する。
- この文書は、外部サイト、画像、別リポジトリ、暗黙のデザインシステムを参照しなくても実装できる内容とする。

## 視覚言語

- 基本パレットを次のように定義する。
  - Canvas: `#fafafa`
  - Ink: `#171717`
  - Muted surface: `#f5f5f5`
  - Hairline: `#ebebeb`
  - Accent: `#ffc799`
- 色数を増やさず、Ink と Canvas の混色で補助的なグレーを作る。
- Canvas 上の非無効の情報文字と操作文字は、混色後のコントラストを 4.5:1 以上にする。
  現在の補助文字色 `#666666` は Canvas に対して約 5.50:1 とし、無効状態だけはこの基準の対象外とする。
- グレーは情報階層、境界、無効状態、背景面を区別するために使用できる。
- 色相を持つアクセントは `#ffc799` だけとし、青や状態ごとの追加色は使用しない。
- Accent は、選択中の翻訳方式、選択中の口調、翻訳方向を示す言語レールなど、
  現在の操作文脈を示す用途に限定する。
- Accent を広い背景面、装飾的なグラデーション、複数の同時強調には使わない。
- エラー時も赤を導入せず、Ink の強い輪郭、状態アイコン、具体的な文言で示す。
- ペインは大きなカードとして浮かせず、背景と 1px の Hairline で区切る。
- 大きな影、ガラス風カード、装飾的なグラデーションは使用しない。
- 角丸は必要な操作部品に限り、小さく統一する。
- 本文の選択色は Ink の背景と Canvas の文字を使用する。
- キーボードフォーカスは 2px の Ink の輪郭で示し、周辺要素と重ならないオフセットを持たせる。
- ヘッダーは Canvas を 75% 以上の不透明度で使用し、背後の内容を妨げない範囲で背景をぼかすことができる。

## 書体

- UI と翻訳本文には `Geist Variable`, `Noto Sans JP Variable`, OS 標準サンセリフの順で指定する。
- メタ情報、文字数、接続状態、補助ラベルには `Geist Mono Variable`, OS 標準モノスペースの順で指定する。
- 書体はアプリ自身が提供し、外部の Web フォント配信へ依存しない。
- 通常本文は 16px を基準とする。
- 原文と訳文は 18px、行高 1.7 を基準とする。
- アプリ名は 16px、600 ウェイト、狭い字間を使用する。
- ペイン見出しとメタラベルは 11px、モノスペース、400 ウェイト、行高 16px、`0.1em` の字間を使用する。
- ボタンと選択肢は 13px から 14px を基準とし、過度な太字を使わない。
- 補助文と状態文は 13px 以上とし、Ink の透明度を下げすぎない。
- 見出しサイズを増やして階層を作りすぎず、余白、境界線、ウェイトで構造を示す。
- 翻訳本文は自然な改行を優先し、文字間隔を人為的に広げない。
- コード、識別子、Markdown 記号はモノスペースへ強制せず、原文と訳文の本文書体の中で表示する。

## 画面構成

- アプリは一つの翻訳画面だけを提供する。
- ページ遷移、サイドバー、タブ式ナビゲーションは設けない。
- 画面はヘッダー、言語方向バー、設定バー、翻訳ワークスペースの順に構成する。
- ヘッダーにはアプリ名と接続状態だけを配置する。
- 歯車アイコン、プロフィール、通知、追加メニューはヘッダーへ配置しない。
- 翻訳ワークスペースは、原文ペイン、言語レール、訳文ペインから構成する。
- デスクトップでは原文と訳文を左右同幅に並べる。
- デスクトップのコンテンツ最大幅は 1,200px を基準とし、左右に最低 24px の余白を保つ。
- 翻訳ワークスペースは、主要な操作が見える範囲で利用可能な画面高を使用する。
- 800px 未満の狭い画面では原文を上、訳文を下へ積み重ね、左右の言語レールを横方向の区切りへ変える。
- 360px 幅まで横スクロールを発生させない。

```text
┌───────────────────────────────────────────────────────────┐
│ Instant Translator                            LOCAL READY │
├───────────────────────────────────────────────────────────┤
│ AUTO   日本語                  ⇄                  ENGLISH │
├───────────────────────────────────────────────────────────┤
│ STANDARD  [ 標準翻訳 | 意訳 ]            TONE  [ 標準 ▾ ] │
├───────────────────────────┬───────────────────────────────┤
│ SOURCE              CLEAR │ TRANSLATION              COPY │
│                           │                               │
│ 入力すると自動で翻訳し    │ 翻訳結果                      │
│ ます                      │                               │
│                           │                               │
│                    0/4000 │                               │
└───────────────────────────┴───────────────────────────────┘
```

## 情報の階層

- 原文と訳文を画面内で最も大きく、最も読みやすい要素とする。
- アプリ名、接続状態、言語方向、設定は翻訳本文より視覚的に弱くする。
- 翻訳方向、翻訳方式、口調は常に確認できるが、本文を不必要に押し下げない。
- 健全な接続状態は小さなモノスペースの文言で控えめに示す。
- 接続に問題がある場合だけ、状態の輪郭と文言を強める。
- 文字数は通常時には目立たせず、3,200 文字を超えると Ink の濃度とウェイトを上げる。
- 各コントロールは一つの役割だけを持ち、同じ操作を複数箇所へ置かない。
- アイコンだけで意味が確定しない操作には、表示ラベルまたは支援技術向けの名前を持たせる。

## ヘッダーと接続状態

- ヘッダーの高さは 56px を基準とする。
- アプリ名は左側、接続状態は右側に配置する。
- 接続済みは `LOCAL READY`、接続確認中は `LOCAL CHECKING`、接続失敗は `LOCAL UNAVAILABLE` と表示する。
- 状態文の前に装飾的な色付きドットを置かない。
- `LOCAL READY` は通常の Ink の 50% から 60% 相当の濃度で表示する。
- 接続失敗時は Ink の濃度を上げ、簡潔な説明と再試行操作を訳文ペインへ表示する。
- 接続確認中や失敗によってヘッダーの高さやアプリ名の位置を変えない。

## 言語方向バー

- 言語方向バーは、原文と訳文の対応関係が分かるように、設定バーより上へ配置する。
- 入力言語、翻訳方向、出力言語を一行で表示する。
- 言語はその言語自身の表記（`日本語` と `ENGLISH`）で示す。
- 行の左端に、自動検出中は `AUTO`、固定中は `FIXED` のメタラベルを表示する。
- `FIXED` はそれ自身が操作であり、押すと自動検出へ戻る。
  自動検出中の `AUTO` は現在の状態を示すだけで、操作できない。
- 入力言語と出力言語の間に、翻訳方向の入れ替え操作を一つだけ置く。
- 入れ替え操作は `⇄` で示し、支援技術向けの名前として「翻訳方向を入れ替えて固定する」を持たせる。
- 入れ替え操作を行うと表示は `FIXED` へ変わり、入力言語と出力言語が入れ替わる。
- 自動検出の判定が曖昧なとき、この行の表示は直前に確定した翻訳方向のまま変えない。
  曖昧であることを示す第三の表示状態は設けない。
- デスクトップでは原文と訳文の間に 1px の言語レールを表示し、翻訳方向を空間的に補強する。
- 狭い画面では言語方向バー自体が上下ペインの関係を示し、言語レールを横方向へ変える。

## 設定バー

- 翻訳方式と口調を、一行のコンパクトな設定バーへ常設する。
- 設定バーは言語方向バーと翻訳ワークスペースの間に配置する。
- 設定バーに歯車アイコン、折りたたみ、追加の設定パネルを設けない。
- `STANDARD` のメタラベルに続けて、「標準翻訳」と「意訳」の二択を表示する。
- `TONE` のメタラベルに続けて、現在の口調を表示する。
- 口調を操作すると「標準」「チャット」「技術文書」「カジュアル」を選択できる。
- 選択中の翻訳方式と口調は Accent の控えめな背景で示す。
- Accent の背景だけに依存せず、文字のウェイト、選択状態、支援技術向け属性でも現在値を示す。
- 翻訳方式または口調を変更すると、メニューを閉じて現在の原文を自動的に再翻訳する。
- 設定バーの高さは選択肢を開閉しても変化しない。
- 口調の選択肢は設定バーへ重ならず、Hairline で囲まれた Canvas のポップオーバーとして一時的に表示する。
- ポップオーバーは大きな影を使わず、1px の Hairline と必要最小限の背景ぼかしで背後から分離する。
- 口調のポップオーバーは選択メニューとして扱い、トリガーは開閉状態と現在の口調を示す。
  メニュー内は現在位置だけを Tab 移動の対象とするロービングフォーカスとし、上下左右矢印で選択せずに移動する。
  Home/End は先頭・末尾へ移動し、Enter/Space またはクリックで選択して閉じる。
  Escape は選択せずに閉じ、トリガーへフォーカスを戻す。

```text
STANDARD  [ 標準翻訳 | 意訳 ]      TONE  [ 標準 ▾ ]
```

## 原文ペイン

- 文字数表示と入力上限は、Unicode の書記素クラスタ（利用者が知覚する 1 文字）で数える。
- ペイン上端に `SOURCE` のメタラベルを左、入力消去操作 `CLEAR` を右へ配置する。
- 空の状態では「入力すると自動で翻訳します」と短く表示する。
- 入力領域は複数行編集に適し、ペイン内の利用可能な高さを使用する。
- 入力領域そのものには追加のカード枠を設けない。
- `CLEAR` は原文がある場合だけ利用できる。
- 文字数はペイン下端へ固定し、入力内容の増減で位置を変えない。
- 3,200 文字を超えると、現在の文字数と 4,000 文字の上限を強調する。
- 4,000 文字を超えた場合は、超過文字数と減らす必要がある文字数を具体的に表示する。
- 上限超過時も原文の編集、選択、コピーを妨げない。
- 入力へ戻ったとき、スクロール位置とカーソル位置を不必要に失わない。

## 訳文ペイン

- ペイン上端に `TRANSLATION` のメタラベルを左、コピー操作 `COPY` を右へ配置する。
- コピー操作は訳文ペインの上端だけに置き、ペイン下端へ重ねて配置しない。
- `COPY` は有効な訳文が存在する場合だけ利用できる。
- コピー成功時は `COPY` を `COPIED` へ短時間切り替え、画面を覆う通知やトーストを追加しない。
- 逐次生成中の訳文と完成済みの訳文を、レイアウトを動かさず同じ領域へ表示する。
- 翻訳状態を次のように表示し分ける。
  - 原文が空: 「翻訳結果」とだけ表示し、説明やイラストを追加しない。
  - 翻訳待機中: 言語レールが動く。直前の訳文がある場合は Ink の濃度を下げて残し、
    現在の結果として扱わない。
  - 翻訳中: 言語レールが動く。最初の訳文が届いた時点で直前の訳文を置き換え、通常の濃度で逐次表示する。
  - 完了: 言語レールの動きを止め、訳文を通常の濃度で表示する。
  - 接続失敗: 「ローカル翻訳に接続できません」と表示し、その直下に `再試行` を配置する。
  - 翻訳失敗: 「翻訳を完了できませんでした」と表示し、その直下に `再試行` を配置する。
  - 入力上限超過: 「原文が 4,000 文字を超えています」と表示し、超過前の訳文を現在の結果として表示しない。
- エラー文は謝罪や曖昧な表現を使わず、何が利用できないかと次の操作を示す。

## モーションとフィードバック

- 主なモーションは、原文から訳文へ処理が進んでいることを示す言語レールの表現に絞る。
- 翻訳待機中と翻訳中は、Accent の短い線または点が翻訳方向に沿って繰り返し移動する。
  デスクトップ（800px 以上）は左から右、狭い画面は上から下へ移動し、レールとペインの大きさは変えない。
- 一回の移動は 500 ミリ秒から 800 ミリ秒を基準とし、連続的な強い点滅を避ける。
- 逐次生成中は文字そのものを主役とし、大きなスピナーやスケルトンで覆わない。
- 処理中を青いスピナーで示さない。
- 完了時に成功色へ切り替えず、言語レールの動きを止めて通常状態へ戻す。
- 入力、設定変更、コピーのフィードバックは即座に返す。
- アニメーションによって本文の位置やペインの大きさを変えない。
- OS の視差効果を減らす設定が有効な場合、言語レールの移動を同じ軸に沿った静的な Accent の短線へ置き換える。

## キーボード操作

- 初回表示時は原文入力へフォーカスする。
- 文字編集、選択、コピー、貼り付け、Undo、Redo は OS とブラウザの標準操作を使用する。
- 翻訳方向の入れ替え、固定の解除、翻訳方式、口調、`COPY`、`CLEAR`、`再試行` へ Tab キーで到達できる。
- Tab 移動の順序は、画面の視覚的な読み順と一致させる。
- Enter、Space、Escape、矢印キーは、各コントロールの一般的なキーボード操作に従う。
- 口調のポップオーバーでは、上下左右矢印で選択せずに項目間を移動し、Home/End で先頭・末尾へ移動する。
  Enter/Space は現在の項目を選択し、Escape は選択せずに閉じてトリガーへフォーカスを戻す。
- アプリ独自のキー組み合わせは設けない。
- ブラウザや OS の標準ショートカットを上書きしない。
- 自動翻訳の開始にキー操作を要求しない。

## アクセシビリティと画面幅

- キーボードだけで原文入力、翻訳方向、翻訳方式、口調、コピー、消去、再試行へ移動できる。
- フォーカス位置を常に視認できる。
- 状態を色だけで伝えない。
- 本文と操作文字は WCAG 2.2 AA 相当のコントラストを持つ。
- 翻訳開始、完了、失敗を支援技術へ通知するが、入力のたびに過剰な読み上げを行わない。
- 逐次生成される各トークンを個別に読み上げず、翻訳開始と完了を状態として通知する。
- 口調の選択肢はキーボードと支援技術から選択でき、現在の選択を通知する。
- 200% まで拡大しても、主要操作と本文が欠落せず、横スクロールを要求しない。
- タッチ操作では、主要な操作対象に 44px 四方相当の操作領域を確保する。
- OS がダークモードの場合でもライトテーマを維持する。

## 受け入れ条件

### 画面の理解

- 初回表示で、原文をどこへ入力し、訳文がどこへ表示されるか理解できる。
- 翻訳ボタンを探さずに、初期値のまま標準翻訳を開始できる。
- 原文と訳文が画面内で最も強い視覚的優先度を持つ。
- 翻訳方向、翻訳方式、口調、接続状態を本文と混同せず確認できる。
- 翻訳中、完了、失敗、上限超過をレイアウトの大きな変化なしに区別できる。
- 入力中や逐次生成中に主要な操作位置が移動しない。
- 履歴、アカウント、共有、候補一覧、解説、仕様外の設定入口が画面へ追加されていない。

### 操作

- コピー操作が訳文ペインの上端にあり、一回の操作でコピーでき、成功を確認できる。
- 入力消去操作が原文ペインの上端にある。
- 翻訳方式と口調を、別の設定画面や折りたたみを開かずに確認・変更できる。
- 標準翻訳と意訳のどちらが選択されているか、色を見分けられなくても判断できる。
- 口調の選択肢を開閉しても、翻訳ペインや主要操作の位置が動かない。
- 設定変更後、翻訳ボタンや確定操作を要求されない。
- 入れ替え操作を行うと `AUTO` が `FIXED` へ変わり、入力言語と出力言語が入れ替わる。
- `FIXED` を操作すると自動検出へ戻る。
- 判定が曖昧なときも、言語方向バーの表示が無言で切り替わらない。

### 画面幅とアクセシビリティ

- デスクトップでは原文と訳文が左右、狭い画面では上下の自然な読み順になる。
- 360px 幅で横スクロールが発生しない。
- 200% 拡大時にも主要操作と本文が欠落しない。
- 初回表示後、クリックせずに原文を入力できる。
- OS 標準のコピー、貼り付け、Undo、Redo を利用できる。
- Tab キーだけで主要な操作へ視覚的な順序で移動できる。
- フォーカス位置を常に視認できる。
- 口調のポップオーバーを Escape キーで閉じ、直前の操作へフォーカスを戻せる。
- ブラウザまたは OS の標準ショートカットがアプリによって上書きされない。
- 翻訳開始のために Enter や独自ショートカットを押す必要がない。

### 視覚言語

- Canvas `#fafafa`、Ink `#171717`、Muted surface `#f5f5f5`、Hairline `#ebebeb` を基本色として使用している。
- 青を含む追加のブランドカラーや状態色が使用されていない。
- 色相を持つアクセントが `#ffc799` に限定されている。
- Accent が画面内の複数箇所で競合せず、現在の操作文脈だけを示している。
- 成功、処理中、警告、失敗を色だけに依存せず判別できる。
- 原文と訳文が 18px 前後、行高 1.7 前後で読みやすく表示される。
- UI 本文、翻訳本文、メタ情報の書体役割が一貫している。
- 外部の Web フォント配信を利用せずに指定書体を表示できる。
- OS がダークモードでもライトテーマの配色が維持される。
- この文書だけで、配色、書体、文字階層、境界、状態表現を判断できる。
