# 翻訳方向とローカル言語判定を廃止し、言語選択をそのままプロンプトへ渡す

原文言語の「自動判定」（文字種によるローカル判定）と、
原文言語と訳文言語から導出していた「翻訳方向」（`ja-to-en` / `en-to-ja`）の概念を廃止する。
原文言語は「指定しない」「日本語」「English」の選択とし、
「指定しない」では原文の言語の解釈を推論先のモデルに委ねる。
明示指定した場合だけ、その言語をプロンプトの翻訳タスクに含める。

廃止の決め手は、判定結果が翻訳品質に元々寄与していなかったことである。
プロンプトは翻訳方向から訳文言語だけを取り出して使っており、
判定した原文言語は「訳文言語と同じなら言語重複として翻訳を止める」ためだけに使われていた。
この言語重複は自動判定経由でしか到達しない状態であり、
判定の三値（日本語・英語・曖昧）、曖昧時のフォールバック、
重複時の警告表示という一連の複雑さを判定機能だけが生んでいた。

一方で判定をやめても失うものはない。
原文の言語はモデル自身が原文を見れば分かるため、
未指定のまま訳文言語だけを指示すれば十分な翻訳が得られる。
訳文言語と同じ言語の原文が来た場合の挙動はモデルの出力に委ね、アプリでは特別扱いしない。
副作用として日英以外の原文も入力できるが、対応言語としては扱わず、結果を保証しない。
