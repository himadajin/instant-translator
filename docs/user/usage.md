# 使い方

導入がまだなら[インストール](installation.md)を先に読む。

## 起動する

翻訳にはローカル推論サーバとアプリの両方が要る。ターミナルを二つ使う。

1. ローカル推論サーバを起動する。

   ```sh
   llama-server -hf LiquidAI/LFM2.5-1.2B-JP-202606-GGUF:Q8_0
   ```

2. リポジトリのディレクトリでアプリを起動する。

   ```sh
   npm run dev
   ```

3. `npm run dev` が表示した URL をブラウザで開く。

画面右上の接続状態が `LOCAL READY` になっていれば翻訳できる。
`LOCAL CHECKING` は接続確認中、`LOCAL UNAVAILABLE` はローカル推論サーバへ接続できていない状態を示す。

## 翻訳する

- 左の `SOURCE` へ日本語または英語を入力すると、入力が止まったところで自動的に翻訳が始まる。
  翻訳ボタンはない。
- 訳文は生成された順に右の `TRANSLATION` へ表示される。
- 訳文をコピーするには、`TRANSLATION` の右にある `COPY` を押す。`COPIED` に変われば成功している。
- 原文を消すには、`SOURCE` の右にある `CLEAR` を押す。訳文と保存された内容も一緒に消える。

## 翻訳方向を変える

言語方向バーは、入力言語、`⇄`、出力言語を一行で示す。

- 初期状態は `AUTO` で、入力した文章から日本語か英語かを判定して方向を決める。
  判定できないときは直前の方向のまま翻訳する。
- `⇄` を押すと方向が入れ替わり、その方向で固定される。表示は `FIXED` に変わる。
- `FIXED` を押すと自動検出へ戻る。

方向を変えると、そのとき入っている原文がすぐ訳し直される。

## 翻訳方式と口調を変える

設定バーは常に見えている。開く操作は要らない。

- `STANDARD` の右で「標準翻訳」と「意訳」を選ぶ。既定は標準翻訳で、原文の意味とニュアンスを保つ。
  意訳は、意図と事実関係を保ったまま表現を整える。
- `TONE` の右で口調を選ぶ。「標準」「チャット」「技術文書」「カジュアル」があり、既定は標準。

どちらも、変更するとそのまま訳し直される。

## 入力できる長さ

- 一度に翻訳できるのは 4,000 文字までである。
- 3,200 文字を超えると、`SOURCE` の下の文字数表示が上限の近いことを示す。
- 4,000 文字を超えた原文は切り詰められないが、その間は翻訳が止まる。
  4,000 文字以下へ戻すと自動的に再開する。
- 長い文章が自動で分割、要約、部分翻訳されることはない。

## うまくいかないとき

- 「ローカル翻訳に接続できません」と出た場合は、`llama-server` が起動しているかを確かめてから
  `再試行` を押す。
- 「翻訳を完了できませんでした」と出た場合も `再試行` を押す。どちらの場合も原文は消えない。

## 保存とプライバシー

- 原文、完成した訳文、翻訳方向、翻訳方式、口調はブラウザの中に保存され、
  ページを再読み込みしても元に戻る。生成の途中で中断しても、最後に完成した訳文は壊れない。
- 翻訳は起動したローカル推論サーバだけで行う。原文と訳文を外部の翻訳サービスやクラウドへ送らない。
- 翻訳履歴は残らない。
