# 使い方

導入がまだなら[インストール](installation.md)を先に読む。

## 起動する

既定のプロファイルはローカルの `llama.cpp` サーバを使うため、
サーバとアプリの両方を起動する。ターミナルを二つ使う。
リモートの推論先を使うプロファイルを選んでいる場合、手順 1 は要らない。

1. `llama.cpp` サーバを起動する。

   ```sh
   llama-server -hf tencent/Hy-MT2-1.8B-GGUF:Q4_K_M
   ```

2. リポジトリのディレクトリでアプリを起動する。

   ```sh
   npm run dev
   ```

3. `npm run dev` が表示した URL をブラウザで開く。

画面右上の接続状態が「接続済み」になっていれば翻訳できる。
「確認中」は接続確認中、「未接続」は選択中のプロファイルの推論先へ
接続できていない状態、「認証エラー」は API キーが受け付けられなかった状態を示す。

画面はライトとダークの両方に対応している。ふだんは OS の設定に従い、
画面右上のボタンで切り替えると、その選択がブラウザに保存される。

## モデルを切り替える

翻訳に使うモデルと接続先は「プロファイル」として登録されている。
画面右上のプルダウンでプロファイルを選ぶと、そのとき入っている原文がすぐ訳し直される。
プロファイルの追加や編集は、プルダウン隣の歯車アイコンから行う。
詳しくは[設定](configuration.md)を見る。

## 翻訳する

- 左の「原文」へ日本語または英語を入力すると、入力が止まったところで自動的に翻訳が始まる。
  翻訳ボタンはない。
- 訳文は生成された順に右の「訳文」へ表示される。
- 訳文をコピーするには、「訳文」の右にある「コピー」を押す。「コピーしました」に変われば成功している。
- 原文を消すには、「原文」の右にある「消去」を押す。訳文と保存された内容も一緒に消える。

## 原文と訳文の言語を変える

原文と訳文の見出しの隣に、それぞれの言語を選ぶプルダウンがある。

- 原文は「自動判定」「日本語」「English」から選ぶ。初期値は「自動判定」で、
  入力した文章から日本語か英語かを判定する。
  判定できた場合はプルダウンの表示が「自動判定 (日本語)」のように変わる。
- 訳文は「日本語」「English」から選ぶ。初期値は「English」とする。
- 原文と訳文に同じ言語を明示指定することはできず、該当する選択肢は無効になる。
- 自動判定した原文言語と訳文言語が同じ場合は翻訳を開始せず、訳文に理由が表示される。
  訳文の言語を別の言語へ変更すると翻訳が始まる。

いずれかの言語を変えると、そのとき入っている原文がすぐ訳し直される。

## 意訳と口調を変える

意訳のチェックボックスと口調は訳文ペインの上部に常に見えている。開く操作は要らない。

- 原文の意味、情報、ニュアンスを保って翻訳する。「意訳」をチェックすると、
  意図と事実関係を保ったまま表現も整える。初期状態ではチェックされていない。
- その隣のプルダウンで口調を選ぶ。「標準」「チャット」「技術文書」「カジュアル」があり、既定は標準。

どちらも、変更するとそのまま訳し直される。

## 入力できる長さ

文字数は Unicode の書記素クラスタ（利用者が知覚する 1 文字）で数える。絵文字、結合文字列、
ZWJ で結合された絵文字も、それぞれ 1 文字として表示と上限判定に用いる。

- 一度に翻訳できるのは 4,000 文字までである。
- 3,200 文字を超えると、「原文」の下の文字数表示が上限の近いことを示す。
- 4,000 文字を超えた原文は切り詰められないが、その間は翻訳が止まる。
  4,000 文字以下へ戻すと自動的に再開する。
- 長い文章が自動で分割、要約、部分翻訳されることはない。

## うまくいかないとき

- 「推論先に接続できません」と出た場合は、選択中のプロファイルの推論先が使える状態か
  （ローカルなら `llama-server` が起動しているか）を確かめてから `再試行` を押す。
- 「API キーが認証されませんでした」と出た場合は、歯車アイコンからプロファイルの
  API キーを確認して保存し、`再試行` を押す。
- 「翻訳を完了できませんでした」と出た場合も `再試行` を押す。いずれの場合も原文は消えない。

## 保存とプライバシー

- 原文、完成した訳文、原文言語、訳文言語、意訳の有無、口調はブラウザの中に保存され、
  ページを再読み込みしても元に戻る。完成した訳文は対応する原文と翻訳条件も一緒に保存されるため、
  条件が一致するときだけ完了として復元される。入力途中の原文が保存されていた場合は、古い訳文を
  current にせず、入力上限以内なら 400 ミリ秒後に自動的に訳し直す。生成の途中で中断しても、
  最後に完成した訳文は壊れない。
- プロファイル（API キーを含む）もブラウザの中に保存される。
- 原文と訳文を送る相手は、選択中のプロファイルの推論先だけである。
  ローカルのプロファイルを選んでいる間は外部へ送られない。
  リモートのプロファイル（OpenRouter、OpenAI など）を選ぶと、原文と訳文はそのサービスへ送られる。
- 翻訳履歴は残らない。
